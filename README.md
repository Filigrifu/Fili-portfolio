🌌 Hero & Visual Identity: Penjelasan tema Retro Cosmic Aurora dengan palet warna neon teal, magenta purple, dan deep nebula dark.
🚀 Fitur Interaktif Utama:
Cinematic Home Hero: Animasi typewriter, shooting star meteors, dan transisi aurora.
Playground Photo Booth: Integrasi kamera langsung, hitungan mundur 4-pose, Selective Color Filter (hanya Hijau & Ungu) dengan manipulasi piksel kanvas real-time, serta ekspor filmstrip vertikal/horizontal.
Sintesis Audio Kosmik (Web Audio API): Suara klik taktis sci-fi, rana kamera mekanik kristal, nada harmonic resonance toggle, dan nada unduhan warp chime.
Galeri Works: Modal penampil slide dengan kontrol panah interaktif.
Terminal Kontak 3D: Kartu flip 3D interaktif depan-belakang.
Navigasi Mobile: Menu hamburger transparan dengan tipografi berpendar tanpa kotak.
🛠️ Teknologi & Arsitektur: Penggunaan HTML5 semantik, Vanilla CSS3, Canvas 2D, Web Audio API, dan MediaDevices WebRTC.
⚡ Petunjuk Menjalankan: Cara membuka langsung di browser atau menggunakan local server (python3 -m http.server).
